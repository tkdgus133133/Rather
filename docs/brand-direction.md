# Rather Be Leather — 브랜드 방향성 작업 노트

> 대화하며 확정/보류한 내용을 기록하는 문서. 확정 항목은 ✅, 작업 중은 🔄.

## 📌 포지셔닝 문장 🔄 (작업 중 — 매 단계 상기)
- 조건: **한 문장, 간결하게 떨어질 것**
- 현재 상태: 미확정 (초안 "명품의 품격과 윤리를 39만 원 안에…"는 반려됨)
- 재료 키워드: 오히려 가죽 / 남겨진 것의 두 번째 삶(부산물 가죽 + 고철 오브제) / 주말·첫 만남 / 39만 원 이하

## 1. 브랜드 철학 ✅
- 의미: "오히려 가죽인 거야"
- 신념: 천연가죽을 사용하지만, 동물복지와 환경에 앞장선다.
- 레퍼런스: Alexander Wang 동물복지 정책
- 약속
  1. 식육 산업 부산물 원피만 사용
  2. LWG 인증 태너리 원단만 사용
  3. ICEC 추적성 인증(TS 410/412) 원단으로 출처 추적 (대안 문구 준비: "ICEC 또는 LWG 추적성 평가")
  4. 퍼·이그조틱·멸종위기종(CITES/IUCN) 사용 금지
- 보류: AS/수선 프로그램 (1인 사업자 규모상 불가) → 관리 가이드 카드·케어 크림 동봉으로 대체 검토

## 2. 타깃 고객 ✅
- 누가: 3040 솔로, 패션을 사랑하는 남성
- 왜: 출근용 백팩이 아닌 주말·소개팅 복장에 맞는 고급스러운 가방이 필요. 합성피혁은 싸구려 티, 명품은 너무 비쌈.

## 3. 가격 ✅
- 입문(크로스백·슬링) 29만 / 메인(메신저·미니 토트) 32만 / 대표(토트·빅토트) 39만
- 상한 39만 — 40~50만대는 코치(남성 45만~) 등 준명품과 겹치므로 금지
- 상시 할인 없는 정가 정책 지향

## 4. 경쟁사 🔄
- 제외: 애프터프레이(잡화·의류), 쿠어(재킷 중심), 아더에러·밀로아카이브(의류, 20대), 도프제이슨(저가 참고용)
- 직접 경쟁(가방 전문, 남성 가죽, 23~46만): 로터프, 만다리나덕, 닥스ACC
- 베지터블/공예 감성 벤치마크: 일비종떼(미니멀 토트 34.2만), 헨더스킴, 아에타(37~54만)
- 상한선: 코치(45만~), 포터 레더 라인

## 5. 제품 메모 🔄
- 대표 제품 아이디어: 베지터블 태닝 빅토트 + 자체 제작 고철 오브제
- 원가 검토 결과: 현 사양은 39만에 빠듯/적자 위험 → 사이즈·구조·원단 구매 방식·오브제 생산 방식 조정 필요 (견적 확인 필요)
